Iowa

Iowa biennial report fee and deadline

Use this page if you need the Iowa biennial report deadline or filing fee. Start with the entity type because Iowa places profit corporations in even-numbered filing years and places LLCs, LLPs, and nonprofits in odd-numbered filing years.

At a glance

Profit corporation lane Profit corporations file in even-numbered years between January 1 and April 1, with the published $60 filing fee.
LLC and LLP lane LLCs and LLPs file in odd-numbered years between January 1 and April 1, commonly at $30 online or $45 by paper.
If the report is missed Iowa sends a delinquency notice after the deadline, and if the report is still not filed by August the entity is dissolved or revoked and has to move into reinstatement work.

Iowa looks simple at first, but the entity type changes both the filing year and the fee lane. The safest shortcut is to split profit corporations from LLC, LLP, and nonprofit filings before you prepare payment.

Profit corporation Iowa corporations use the even-year lane

Business corporations file biennial reports in even-numbered years and use the published $60 filing fee.

LLC or LLP Most Iowa pass-through entities use the odd-year lane

Iowa LLCs and LLPs file in odd-numbered years and commonly use the lower online fee if they stay inside Fast Track Filing.

Nonprofit corporation The due window matches the LLC lane, but the fee does not

Iowa nonprofits still file in odd-numbered years, but the state says nonprofits do not pay a filing fee for the biennial report.

Already late The real risk starts after the April window

Once the report is missed, Iowa issues a delinquency notice and can dissolve or revoke the entity by August if the filing still is not completed.

Question What due date should I start with for Iowa?

The main due date on this page is January 1 through April 1 in an odd or even year depending on entity type. If the state uses anniversary, report-month, or fiscal-year timing, the official state record still controls.

Question What fee or amount does this page show?

The main amount on this page is $60 for profit corporations, $30 online or $45 paper for many LLC and LLP filings, or no fee for nonprofits. If the amount changes by entity type, filing method, or status, confirm it on the official state source before paying.

Question What if I am already late?

Delinquency notice after the miss, then dissolution or revocation if the report still is not filed by August. Confirm the current status and amount on the official state record before you pay or file.
