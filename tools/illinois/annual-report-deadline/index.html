Illinois

Illinois annual report fee and deadline

Use this page if you need the Illinois annual report deadline or filing fee. Start with the entity type because Illinois puts corporations, LLCs, and nonprofits on anniversary-month timing but uses different fee and late-penalty rules for each lane.

Recently checked Checked: June 8, 2026 Reviewed by FinLogic Hub Editorial Team 8 official sources Source: Illinois Secretary of State

At a glance

Corporation lane $75 annual report filing fee, plus annual franchise tax and any accrued late charges.
LLC lane $75 filing fee, with a $100 late penalty if the report is not filed within 60 days after the due date.
Nonprofit lane $10 if filed on time, with a statutory $3 late penalty if filed after the due date.

Illinois looks like one anniversary-month system at first, but the practical answer changes fast when you separate corporations, LLCs, and nonprofits. Corporations also bring franchise-tax math into the filing, while LLCs and nonprofits use cleaner flat-fee annual-report lanes.

Quick questions

What most filers need to know first

These answers keep the page short while still covering the questions people ask before they file.

Question Who should use this Illinois guide?

Use this page for Business corporations, LLCs, and nonprofit corporations. Match the entity type on the official state record before you rely on the summary.

Question What due date should I start with for Illinois?

The main due date on this page is Prior to the first day of the anniversary month each year. If the state uses anniversary, report-month, or fiscal-year timing, the official state record still controls.

Question What fee or amount does this page show?

The main amount on this page is $75 for corporations, $75 for LLCs, or $10 for nonprofits, with separate late and franchise-tax rules by entity type. If the amount changes by entity type, filing method, or status, confirm it on the official state source before paying.

Question What if I am already late?

LLCs add a $100 late penalty after 60 days; nonprofits add a $3 statutory late penalty. Confirm the current status and amount on the official state record before you pay or file.
